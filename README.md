# TraKr
This will be a software used to gather data from multiple computers (nodes) to a central computer (main node).

The purpose of this is to gather the data from multiple computers, information such as CPU/GPU/RAM usage, OS information, and more is to be gathered by this application. All gathered information would be sent to, as said before, to a central computer which be an HTTP server serving all the information to a website.

This is done in Zig, which I am learning along the way, so it is going to take a pretty good time ngl.
